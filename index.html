The medical world model

The first world model of the human patient.

Language models know about medicine. A world model knows the patient. It predicts how one specific person will evolve over the next weeks and months, and how that future changes with every intervention we could choose. This is the operating system of the AI hospital.

Safety by design

Agents act in a sandbox before they act on a patient.

A hospital cannot debug in production. Every agent action runs first in an isolated environment against the world model, and only verified behaviour moves forward.

Isolated execution

Each agent, analysis and computer-use session runs in its own disposable sandbox with only the access it was granted.

Simulate, then decide

Thousands of parallel rollouts per decision, so agents compare options instead of committing to their first guess.

Know when to defer

Calibrated uncertainty and reproduction checks decide when an agent hands a case to a human.
